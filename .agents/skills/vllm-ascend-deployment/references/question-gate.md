# Question gate

Ask the user only when the answer is both:

- important enough to change topology, feature policy, or the ability to synthesize a script
- not already obtainable from repo, local source, or local artifacts

Typical blocker questions:

- exact model path / remote id
- A2 card count
- average input / output length
- max context length
- TPOT / SLA
- whether a near model name is a typo or a real custom model
- whether a quantized weight artifact already exists
